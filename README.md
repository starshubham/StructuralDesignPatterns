# StructuralDesignPatterns

Structural design patterns deal with how classes and objects are composed to form larger structures while keeping the system flexible and loosely coupled. The Adapter handles incompatible interfaces, Bridge separates abstraction from implementation, Composite represents hierarchical structures, Decorator adds behavior dynamically, Facade simplifies complex subsystems, Flyweight reduces memory by sharing common state, and Proxy controls access to another object.

| Pattern       | What problem does it solve?                   | Key idea |
| ------------- | --------------------------------------------- | -------- |
| **Adapter**   | Incompatible interfaces                       | Convert  |
| **Bridge**    | Abstraction tightly coupled to implementation | Separate |
| **Composite** | Hierarchical/part-whole structures            | Tree     |
| **Decorator** | Need additional behavior                      | Wrap     |
| **Facade**    | Complex subsystem                             | Simplify |
| **Flyweight** | Too many similar objects                      | Share    |
| **Proxy**     | Need controlled access                        | Control  |
